### Sutututu — 主軸プロジェクト

実際のサーキット走行を、ゲームのように挑戦を重ねられる体験へつなぐモータースポーツアプリです。二輪・四輪を対象に、**計測 → 記録 → 比較 → 次の挑戦 → 改善**という流れを設計しています。

GPSによるラップ計測・記録保存を基盤に、ランキングや記録の共有、過去の自分や他の走行記録と比較する **GHOST RACE** を組み合わせています。目指すのは、走行後も自分の記録から比較相手や次の目標が見つかり、次の走行機会につながる体験です。

**担当領域：** 課題探索・プロダクト企画、UX/UI設計、Web・モバイル・API開発、リリースと運用、継続利用の設計、広告などによる初期ユーザー獲得。

サーキット走行の頻度を踏まえ、**次の走行機会にもSutututuを選んでもらうこと**を継続利用の中心に置いています。直近60日間のアクティブユーザー（60AU）や次回走行時の再利用を捉える指標設計、報酬・テーマ・通知による体験づくり、初期獲得施策を進め、実際の利用を通じて検証する段階です。

**主な技術・領域：** React Native / Expo / TypeScript / Next.js / Firebase / PostgreSQL / SQLite / プロダクト企画 / UX/UI設計 / 継続利用・獲得施策

## 技術と取り組み方

- **Web開発：** TypeScript・React・Next.jsを中心とした画面とアプリケーションの実装、WordPressを用いたコンテンツ管理。
- **モバイル開発：** React Native・ExpoによるiOS／Android対応、GPSを使った計測体験、SQLiteによる端末内保存、ストア配布・運用。
- **バックエンド：** Go・Node.jsによるAPI開発、PostgreSQL・MySQLを用いたデータ設計。
- **開発環境・運用：** Git・Docker・Linux・Vercelを用いた開発と公開。
- **プロダクトと集客：** 課題探索、要件定義、UX/UI・情報設計、継続利用と指標の設計、広告・SEOによる獲得、公開後の分析・改善。
- **AI活用：** 調査・設計・実装・コンテンツ制作に生成AIを取り入れ、出力を確認しながら開発と検証を進める。

技術選定では、実装のしやすさに加えて、運用費用や更新の手間も考慮しています。個人で継続して運営できる構成を重視しています。
